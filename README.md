## Запуск

Нужен Node.js 22.12+.

```sh
npm ci
npm run dev
```

Откройте адрес, который покажет терминал. Для production-сборки:

```sh
npm run build
npm run preview
```

## Соответствие требованиям

| Требование | Реализация |
| --- | --- |
| Добавление и удаление | `BookForm` и кнопка удаления каждой книги |
| Изменение статуса | Select: В планах / Читаю / Прочитано |
| Локальное состояние элемента | `pagesRead` и `note` в `BookCard` через `useState` |
| Фильтрация | По статусу и названию/автору |
| Изменение порядка | Копирование массива и `.reverse()` |
| Сохранение локального состояния | Стабильный ключ `id:edition`; скрытые карточки остаются смонтированными |
| Намеренный сброс с помощью key | Кнопка увеличивает `edition` только выбранной книги |
| Исследование повторных рендеров | `console.log` в `App` и `BookCard` |
| Состояние родителя и детей | Список/фильтры в `App`; страницы/заметка в `BookCard`; поля в `BookForm` |
| Props | Данные и обработчики передаются дочерним компонентам |
| Условный рендеринг | Форма добавления и пустой результат |
| `.map()` и стабильные ключи | Список книг, фильтры, опции статусов |
| Несколько свойств у элемента | id, title, author, pages, status, edition, color |
| SPA и CSS | Один React root, адаптивное оформление |
| Запрещённые инструменты | Нет useEffect, Context, Redux или внешних библиотек состояния |

## Важные детали

- Фильтрация использует `hidden`. Если удалить карточку из React-дерева через `.filter(...).map(...)`, React уничтожит её локальное состояние. Один стабильный key не сохранит состояние после размонтирования.
- При обычных действиях ключ не меняется. `edition` меняется только при намеренном сбросе. Индекс массива используется лишь для номера строки, а не для `key`.
- Сброс очищает страницы и заметку, но сохраняет название, автора и статус в родительском состоянии.
- Статус — ручная категория книги. Страницы и заметка — отдельный локальный черновик текущей сессии; статус «Прочитано» не задаёт счётчик автоматически.
- Счётчик ограничен общим количеством страниц. Когда достигнут максимум, кнопка отключается.
- Данные находятся в памяти. Перезагрузка страницы восстанавливает исходные книги. Постоянное хранение не требуется заданием.
- Все функциональные компоненты объявлены на уровне модуля, а не внутри `App`.

## Структура

```text
src/
  App.jsx                  # Родительское состояние и композиция
  data.js                  # Исходные книги и статусы
  main.jsx                 # React root
  styles.css               # Адаптивный CSS
  components/
    BookCard.jsx           # Локальные страницы и заметка
    BookForm.jsx           # Форма добавления
    Toolbar.jsx            # Фильтры, поиск, порядок
```

## GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает приложение и публикует `dist` при push в `main`. Источник Pages в настройках репозитория — **GitHub Actions**. Относительный `base: './'` позволяет запускать приложение по адресу репозитория.
